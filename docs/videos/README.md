Recorded on 20 November 2026 with the custom figure/stop-sign model and the
single-box overlay. The first source recording was `2026-11-20 13-04-58.mp4`;
the second was `2026-11-20 13-06-53.mp4`. The repository copies preserve the full
duration and are encoded as H.264, 1280 × 800, 15 FPS for compact playback.

The root README uses GitHub-hosted video attachments for inline players and
relative links to these files as an offline/download fallback. The clips are
qualitative demonstrations in one setup, not a latency or detection benchmark.
